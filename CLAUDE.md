# Instruções do projeto

- **Identidade visual:** todo elemento visual novo ou alterado (site, painel, boletim, PDFs,
  imagens, apps) deve seguir `docs/IDENTIDADE-VISUAL.md`, que resume o Manual da Marca oficial
  (`docs/marca/`). Use os tokens de `src/styles.css` e os arquivos de `public/marca/` — nunca
  cores, fontes ou logos fora do manual.
- Não reescreva histórico publicado do git (sem force push, rebase ou amend de commits enviados).
